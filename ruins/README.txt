SRI SHIVAN ALAYAM - ANCIENT COURTYARD

This is a new real-time, first-person environment. The architecture is generated in ruins.js from stone courses, shaped columns, continuous carved lotus relief surfaces and hinged doors. It does not load the old simplified temple model or play a background movie.

Controls: WASD or arrow keys to walk, mouse drag to look, Shift to move faster, Escape for controls. Touch arrows move on phones; drag the scene to look. The doors open when approached. Walls, columns, the altar and courtyard boundary stop movement. Pause atmosphere stops plant movement and flame flicker.

Visual features: photographed stone base-color/normal/roughness maps, scanned rocks and vegetation, environment lighting, shadow maps, screen-space ambient occlusion on desktop, restrained bloom, anti-aliasing, and distance fog. Desktop uses 2K surface textures; mobile uses 1K textures and fewer plants. The original tree mesh was reduced from 1,599,403 to 95,000 triangles for this scene.

Third-party assets: Poly Haven CC0 library. Individual sources are listed in assets/sources.json. License: https://polyhaven.com/license
Three.js modules are pinned to r180, under the project's existing vendor directory and MIT license.

This is an artistic ancient-temple environment, not a measured reconstruction of the actual temple. This first environment pass establishes the new art direction and movement. Bespoke sculptural figures, a larger environment and further material/lighting work would be needed to approach the reference game's production quality.

Open using a local HTTP server at /ruins/. All runtime assets are bundled. The source scripts and raw asset downloads used during preparation remain in the Codex task workspace.
