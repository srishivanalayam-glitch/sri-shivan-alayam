SRI SHIVAN ALAYAM - REAL-TIME JOURNEY

Open /live/ using a local HTTP server. Scroll or use chapter buttons to travel. Begin journey / Play journey runs the camera automatically over approximately 70 seconds. Wheel, touch, navigation keys or Escape stop playback. Drag with a mouse to look around temporarily. Pause atmosphere freezes cloud drift, Earth rotation, petals and flickering light. Reduced-motion preferences start the atmosphere paused and remove scroll interpolation.

This is actual Three.js rendering, not video or animated background photographs. The Earth is a textured sphere, clouds are moving procedural sprites, the temple is the existing Blender-exported GLB, and two hinged brass doors open according to camera position. The architecture remains a stylized model; it does not reproduce the photorealistic reference artwork's carved detail.

The old cinematic page is preserved at /cinematic.html, and the original 3D walkthrough at /temple/.

Asset source: Earth surface texture downloaded from the Three.js examples asset collection:
https://threejs.org/examples/textures/planets/earth_atmos_2048.jpg
Three.js repository and license: https://github.com/mrdoob/three.js
All other live scene elements are procedural code or the existing project model. No external network connection is needed at runtime.
